Illustrator Automation Plugin — JavaScript
==========================================

**Stack:** JavaScript, Adobe Illustrator ExtendScript

.. image:: /_static/images/software/illustrator-plugin.jpg
   :width: 100%

This project follows the same automation philosophy as the Photoshop plugin,
except it targets Adobe Illustrator workflows. It is designed to replace Smart
Object assets across artboards and export renamed PNG files for print-ready use.

Problem It Solves
-----------------

Illustrator-based production work often involves repeated object swaps and
export steps. Doing that manually across many artboards is slow and repetitive,
particularly when each output needs a specific naming convention.

How It Works
------------

The plugin automates smart object replacement across multiple artboards and
produces exported files with consistent names. That makes it well suited for
repeatable print and packaging workflows.

Benefits
--------

- reduces repetitive manual work
- standardizes exported filenames
- accelerates production cycles
- improves consistency across design batches

Outcome
-------

The project demonstrates a strong focus on design workflow automation and shows
how simple scripting can remove friction from creative production pipelines.
