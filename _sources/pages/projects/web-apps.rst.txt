   .. grid-item-card:: Photoshop Automation Plugin — JavaScript
      :shadow: md

      Written in JavaScript as a Photoshop plugin. Takes an input image and a
      template with Smart Object layers, automatically replaces them, and
      generates renamed output files per artboard. Built out of desperation for
      a repetitive batch process — now 150 items done in a day without being
      near the computer.

   .. grid-item-card:: Illustrator Automation Plugin — JavaScript
      :shadow: md

      Similar to the Photoshop plugin, written in JavaScript for Adobe
      Illustrator. Automates smart object replacement across artboards and
      exports renamed PNG files ready for the printing press.
