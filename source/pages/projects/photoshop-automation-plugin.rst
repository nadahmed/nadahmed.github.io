Photoshop Automation Plugin — JavaScript
========================================

**Stack:** JavaScript, Photoshop ExtendScript

.. image:: /_static/images/software/photoshop-plugin.png
   :width: 100%

This project started as a practical solution to a repetitive design task. It is a
Photoshop plugin written in JavaScript that automates the replacement of Smart
Object layers and outputs renamed files for each artboard.

Problem It Solves
-----------------

Manual batch work in Photoshop becomes tedious very quickly, especially when the
same transformation must be applied across many artboards. The plugin removes the
repetitive clicking and file handling so the entire process becomes predictable
and much faster.

How It Works
------------

The plugin accepts an input image and a template file with Smart Object layers.
It then swaps the assets automatically and generates renamed output files for
each board in the document, making it suitable for production-style workflows.

Why It Was Useful
-----------------

The tool was built out of frustration with a repetitive task that had no good
automation path at the time. It quickly became valuable because it reduced the
manual work dramatically and made batch production far less error-prone.

Outcome
-------

What began as a personal productivity tool evolved into a reliable workflow
helper that could process a large number of items in a single session without
constant supervision.
