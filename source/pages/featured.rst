AI-Augmented Systems & Agentic Workflows
----------------------------------------
* **The Challenge:** Moving beyond "vibe-based" AI development to deterministic, production-ready agentic systems.
* **Architecture:** 
    * Built autonomous research and coding agents using frameworks like ZeroClaw/OpenClaw.
    * Implemented Retrieval-Augmented Generation (RAG) pipelines with vector databases for grounded, fact-checked outputs.
    * Integrated strict CI/CD guardrails for LLM-generated code, including automated execution and error-traceback feedback loops.
* **Outcome:** Dramatically accelerated software delivery cycles by automating boilerplate generation, bug patching, and documentation synthesis, while maintaining high code quality standards.

.. note:: 
   My AI approach focuses on "System Thinking"—building the plumbing (pipelines, evaluation, cost management) that makes LLMs useful for commercial products.

SulfurBook: Double-Entry Bookkeeping Engine
-------------------------------------------
* **The Challenge:** Existing open-source accounting solutions lacked the extensibility for custom financial reporting modules.
* **Architecture:** Built on a strict double-entry ledger logic. FastAPI backend for high-throughput transaction processing; Next.js frontend with Shadcn UI for real-time financial visualization.
* **Outcome:** Created a robust, idempotent system capable of handling complex audit trails and multi-currency support.

SharkRaven: Multi-Branch Gym Management
---------------------------------------
* **The Challenge:** Building a unified ecosystem for high-traffic physical fitness centers with varying membership tiers.
* **Architecture:** Multi-tenant SaaS architecture with custom Role-Based Access Control (RBAC). Integrated biometric attendance hardware with a centralized web-based management dashboard.
* **Outcome:** Automated facility access, reduced manual administrative overhead, and provided granular usage analytics for multi-branch management.

AgniStop: Industrial IoT Safety
-------------------------------
* **The Challenge:** Implementing reliable fire safety monitoring in environments where standard network infrastructure is unavailable or unreliable.
* **Architecture:** Deployed LoRaWAN-based sensor arrays for long-range, low-power communication. C++ firmware on ESP32 controllers; custom MQTT-based backend for real-time alerts.
* **Outcome:** Successfully demonstrated long-range, industrial-grade reliability in high-interference settings with near-zero latency in alert propagation.
